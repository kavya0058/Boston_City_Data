# Top 5 Earners in Boston City

## Project Description

This project displays the top 5 highest-earning people in Boston City.

The data is loaded from a JavaScript data file and processed using JavaScript. The salary values are sorted in descending order to identify the highest earners.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Displays the top 5 earners in Boston City
- Sorts people based on salary
- Shows the person's name and salary
- Uses JavaScript array methods like `sort()` and `splice()`
- Displays the output dynamically using `innerHTML`
- Uses a Boston city background image

## How It Works

1. The Boston data is loaded from `data.js`.
2. The data is sorted based on salary in descending order.
3. The first 5 highest earners are selected.
4. Their names and salaries are displayed on the webpage.
5. JavaScript dynamically creates the HTML list.
